Components

The registered library — these are the only elements the canvas editor can drop onto a page. Enabling something here makes it available to non-dev authors; disabling removes it from their palette. Each ships with its own registered variants.

This is the whole vocabulary a client can build with. No page-builder primitives, no arbitrary blocks — only what's registered here (plus the single Embed escape hatch for third-party HTML). New component? A developer registers it, and it appears in the canvas.

CSS / Tailwind

The design system source. Tokens are values, Classes are the closed vocabulary the validator enforces, Custom CSS is the escape hatch. The output engine toggle decides whether the framework emits plain CSS or Tailwind.

site/styles/tokens.css read-only · values 

          

        


        

          
          
Closed vocabulary. The Classes layer is the complete set of class names any page may use. The validator rejects anything outside it on save — this is what keeps agent-authored and human-authored HTML in lockstep, and what makes the canvas editor safe to hand to a client.

Roles & Access

          
Three built-in roles decide who sees what — in this settings area and inside the canvas editor. Like Webflow or Sanity: the further from Developer, the fewer surfaces are exposed. This is the guardrail that keeps a client from touching structure, CSS, or deploy.

        


        

          

            

              
              

                
Developer

                
Full control · maps to WP Administrator

              

            

            
Sees and does everything. The only role that touches the closed vocabulary, template structure, CSS/Tailwind, integrations, roles, and deploy.

          


          

            

              
              

                
Marketer

                
Content + Style + Advanced · maps to WP Editor

              

            

            
Edits content, component variants & sizing, plus per-element Advanced (SEO, tag, visibility). Can open Theme Settings, but not Roles, CSS/Tailwind, or Deploy.

          


          

            

              
              

                
Client

                
Content + Style only · maps to WP Author

              

            

            
In the canvas, sees only the Content and Style tabs — no Advanced, no structure surgery. Never sees this settings page at all.
